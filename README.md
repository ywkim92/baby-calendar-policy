# 우리아이 접종노트 개인정보처리방침

**시행일: 2026년 5월 20일**

"우리아이 접종노트"(이하 "본 앱")는 사용자의 개인정보를 소중하게 다루며, 관련 법령을 준수하기 위해 다음과 같은 처리방침을 두고 있습니다.

## 1. 수집하는 정보 및 처리 목적

본 앱은 사용자가 직접 입력한 다음 정보를 사용자의 iOS 기기 내부에만 저장합니다.

| 항목 | 처리 목적 |
|---|---|
| 아기의 이름 | 알림 및 화면 표시 |
| 아기의 생년월일 | KDCA 표준예방접종일정표 기반 일정 자동 생성 |
| 일정 제목, 날짜, 메모, 약품명 | 사용자가 등록·관리하는 접종/수동 일정 |
| 알림 시점 설정값 | 로컬 알림 발송 시점 조정 |

본 앱은 위 정보 외에 어떠한 식별자(광고 식별자, 위치 정보, 연락처, 기기 식별자 등)도 수집하거나 처리하지 않습니다.

## 2. 외부 전송 및 제3자 제공

**본 앱은 어떠한 정보도 외부 서버로 전송하지 않습니다.**

- 분석 도구(Analytics) 미사용
- 광고 SDK 미사용
- 클라우드 동기화 미사용
- 제3자 제공 없음

iOS 의 기본 iCloud 백업이 활성화된 경우, 앱 데이터가 Apple 의 iCloud 백업에 포함될 수 있습니다. 이 경우 백업 처리 정책은 Apple 의 [개인정보처리방침](https://www.apple.com/legal/privacy/) 을 따릅니다.

## 3. 알림 권한

본 앱은 예방접종 일정 알림을 위해 iOS 로컬 알림 권한을 사용합니다. 알림은 기기 안에서만 처리되며 외부로 전송되지 않습니다. 알림 권한은 iOS 설정 앱에서 언제든 변경할 수 있습니다.

## 4. 만 14세 미만 아동의 정보

본 앱은 보호자가 자녀의 예방접종 일정을 관리하기 위한 도구이며, 아동이 직접 사용하는 것을 전제로 하지 않습니다. 아동에 관한 정보(이름, 생년월일)는 보호자가 입력한 형태로 사용자의 기기에만 저장되며 외부로 전송되지 않습니다.

## 5. 보유 및 파기

- 앱 내에서 아기 정보 삭제 시: 해당 아기의 모든 일정이 즉시 삭제됩니다.
- 앱을 기기에서 삭제할 경우: 저장된 모든 데이터가 함께 삭제됩니다.

별도의 데이터 보관 서버가 존재하지 않으므로, 위 시점 외 별도의 파기 절차는 없습니다.

## 6. 이용자의 권리

본 앱은 모든 데이터를 사용자 기기에만 저장하므로, 이용자는 앱 내에서 직접 정보 열람·수정·삭제가 가능합니다.
